우항에 있는 피연산자의 평가 결과를 좌항에 있는 변수에 할당하는 연산자. 좌항의 변수에 값을 할당하여 부수효과가 존재한다. 또한, 값으로 평가되는 [표현식](표현식.md)인 문으로서 할당된 값으로 평가된다.

| 연산자  | 의미          |
| ---- | ----------- |
| `=`  | 단순 할당       |
| `+=` | `x = x + 5` |
| `-=` | `x = x - 5` |
| `*=` | `x = x * 5` |
| `/=` | `x = x / 5` |
| `%=` | `x = x % 5` |
