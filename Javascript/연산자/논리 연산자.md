피연산자를 논리 연산한 결과를 반환하는 연산자

| 연산자    | 의미              |
| ------ | --------------- |
| `\|\|` | 논리합(OR)         |
| `&&`   | 논리곱(AND)        |
| `!`    | 부정(NOT), 단항 연산자 |
- 부정 연산자는 항상 [Boolean 타입](Boolean%20타입.md)의 값을 반환한다.
- 논리합과 논리곱 연산자의 표현 결과는 [Boolean 타입](Boolean%20타입.md)의 값이 아니라 다른 하나의 값으로 평가될 수 있으며 이러한 기능을 단축 평가라고 한다.
