피연산자를 대상으로 수학적 계산을 수행해 새로운 숫자 값을 만드는 연산자. 산술 연산이 불가능한 경우 `NaN`을 반환한다.
## 이항 산술 연산자
2개의 피연산자를 산술 연산하여 숫자 값을 만든다. 부수 효과 없이 새로운 값을 생성한다.

| 연산자 | 의미  |
| --- | --- |
| `+` | 덧셈  |
| `-` | 뺄셈  |
| `*` | 곱셈  |
| `/` | 나눗셈 |
| `%` | 나머지 |
## 단항 산술연산자
1개의 피연산자를 산술 연산하여 숫자 값을 만든다. 부수 효과가 있을 수 있다.

| 연산자  | 의미                         |
| ---- | -------------------------- |
| `++` | 피연산자의 값을 1 증가시킴            |
| `--` | 피연산자의 값을 1 감소시킴            |
| `+`  | 어떠한 효과 x. 음수를 변환하지도 않음     |
| `-`  | 양수를 음수로, 음수를 양수로 반전한 값을 반환 |
> 증가/감소 연산자는 위치에 따라 반환 결과가 달라진다.
> - 전위에 위치한 경우 먼저 값을 증가/감소시키고 그 결과를 반환한다. 
> - 후위에 위치한 경우 먼저 현재 값을 반환하고, 값을 증가/감소시킨다.
