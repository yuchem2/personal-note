피연산자를 비교한 다음 그 결과를 [Boolean 타입](Boolean%20타입.md)의 값으로 반환하는 연산자
## 동등/일치 비교 연산자

| 연산자   | 의미     | 설명              |
| ----- | ------ | --------------- |
| `==`  | 동등 비교  | 피연사자의 값이 같음     |
| `===` | 일치 비교  | 피연사자의 값과 타입이 같음 |
| `!=`  | 부동등 비교 | 피연사자의 값이 다름     |
| `!==` | 불일치 비교 | 피연사자의 값과 타입이 다름 |
동등 비교 연산자는 비교하기 전에 피연산자를 먼저 암묵적 타입 변환을 통해 타입을 일치 시킨 뒤 같은 값인지 비교한다. 이에 비해 일치 비교 연산자는 피연산자의 타입과 값이 모두 같아야 `true`를 반환하기 떄문에 일반적으로는 예측하기 쉬운 **일치 비교 연산자**를 비교에 사용한다.

```js
5 === 5; // true
5 == '5'; // true
5 === '5'; // false
NaN === NaN; // false // 유일하게 자신과 일치하지 않음으로 주의할 필요가 있
```

> ES6에서 도입된 `Object.is` 메서드는 항상 예측 가능한 정확한 비교를 반환한다. 
> ```js
> -0 === +0; // true
> Object.is(-0, +0); // false
> NaN === NaN; // false
> Object.is(NaN, NaN); // true
> ```
## 대소 관계 비교 연산자
피연사자의 크기를 비교하여 [Boolean 타입](Boolean%20타입.md)의 값을 반환한다.

| 연산자  | 의미                              |
| ---- | ------------------------------- |
| `>`  | 좌항의 값보다 우항의 값이 큰 경우 `true`      |
| `<`  | 좌항의 값보다 우항의 값이 작은 경우 `true`     |
| `>=` | 좌항의 값보다 우항의 값이 크거나 같은 경우 `true` |
| `<=` | 좌항의 값보다 우항의 값이 작거나 큰 경우 `true`  |
