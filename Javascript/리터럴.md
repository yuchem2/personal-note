자바스크립트 엔진이 평가할 수 있는 [리터럴](programming%20basis/리터럴.md)은 다음과 같다.


| 리터럴       | 예시                                  | 비고               |
| --------- | ----------------------------------- | ---------------- |
| 정수        | `100`                               |                  |
| 부동소수점     | `10.5`                              |                  |
| 2진수       | `0b0100001`                         | 0b로 시작           |
| 8진수       | `0o101`                             | ES6에서 도입. 0o로 시작 |
| 16진수      | `0x41`                              | ES6에서 도입. 0x로 시작 |
| 문자열       | `'Hello'`, `"World"`                |                  |
| 불리언       | `true`, `false`                     |                  |
| null      | `null`                              |                  |
| undefined | `undefined`                         |                  |
| 객체        | `{ name: 'Lee', address: 'Seoul' }` |                  |
| 배열        | `[ 1, 2, 3 ]`                       |                  |
| 함수        | `function() {}`                     |                  |
| 정규 표현식    | `/[A-Z]+/g`                         |                  |
