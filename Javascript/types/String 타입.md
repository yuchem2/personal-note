텍스트 데이터를 나타내며 UTF-16 코드 단위 수를 나타내는 16비트 부호 없는 정수 값의 나열로 인코딩된다. `String`의 길이는 UTF-16 코드 단위의 수이며, 실제 유니코드 문자 수와 일치하지 않을 수 있다. 

문자열은 작은 따음표(''), 큰따음표("") 또는 [백틱(\`\`)](템플릿%20리터럴.md)으로 텍스트를 감싸 표현할 수 있다.
```js
var string;
string = '문자열';
string = "문자열";
string = `문자열`;
```

JS에서 String 타입 값은 생성되면 수정될 수 없는 **변경 불가능한 값**이다.
