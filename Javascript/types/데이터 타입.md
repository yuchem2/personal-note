JS는 ES6 기준으로 7개의 데이터 타입, ES11 기준으로 8개의 데이터 타입을 제공한다. 크게 원시 타입(primitive type)과 객체 타입(object/reference type)으로 구분할 수 있다.
## 원시 타입
`Object`를 제외한 모든 타입은 언어의 최하위 수준에서 직접 표현되는 불변 값을 정의한다. 이러한 타입의 값을 원시 값이라고 한다.

| Type                              | `typeof` return value | Object wrapper |
| --------------------------------- | --------------------- | -------------- |
| [Null 타입](Null%20타입.md)           | `"object"`            | N/A            |
| [Undefined 타입](Undefined%20타입.md) | `"undefined"`         | N/A            |
| [Boolean 타입](Boolean%20타입.md)     | `"boolean"`           | `Boolean`      |
| [Number 타입](Number%20타입.md)       | `"number"`            | `Number`       |
| [BigInt 타입](BigInt%20타입.md)       | `"bigint"`            | `BigInt`       |
| [String 타입](String%20타입.md)       | `"string"`            | `String`       |
| [Symbol 타입](Symbol%20타입.md)       | `"symbol"`            | `Symbol`       |
- [`null`](Null%20타입.md): 어떤 값이 의도적으로 비어있음을 표현하는 타입
- [`undefined`](Undefined%20타입.md):  값이 할당되지 않은 변수에 JS 엔진이 기본적으로 부여하는 타입이자 값
- [`boolean`](Boolean%20타입.md): 논리적 참과 거짓
- [`Number`](Number%20타입.md): 정수와 실수 구분 없이 하나의 숫자 타입으로 관리
- [`BigInt`](BigInt%20타입.md): ES11에서 추가된 타입으로 `number`이 표현할 수 있는 정수보다 높은 값을 사용하기 위한 타입
- [`string`]((String%20타입.md): 문자열
- [`symbol`](Symbol%20타입.md): ES6에서 추가된 7번째 타입으로, 고유함이 보장되는 타입
## 객체 타입
원시 타입을 제외한 모든 값은 JS에서는 객체 타입으로 다뤄지며 유일한 변경 가능한 값이다.
