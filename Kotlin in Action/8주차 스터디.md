- 어노테이션 = 타입스크립트의 데코레이터에서 많이 사용했고, 구현도 해봤어서 쉽게 읽었다. 코틀린에서는 어노테이션을 이렇게 다루는구나. 리플렉션을 통해 런타임에 정보를 얻는 점도 유사해서 쉽게 읽었던 것 같다.
- DSL = DSL이라는 키워드에 숨겨진 수신 객체 람다를 받는 함수를 구현하고, 활용할 수 있는 방법을 보여주는 챕터라고 느낌. 이걸 잘 사용하면 보다 코드를 쉽고 간단하게 작성할 수 있다고 생각이 들었음. 리액트 네이티브를 쓸 때 gradle 문법을 코틀린으로 써야했는데, 이 챕터를 읽으면서 해당 부분이 이런식으로 구현되었겠구나를 느낌
- DSL 예시를 보다 보니 이전에 한빈님이 짚어주셨지만, 중위 호출을 적절히 사용한다면 코드를 더 읽기 쉽게 짤 수 있다는 것을 느꼈음.
