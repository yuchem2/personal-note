## 누적합
> 특정 구간의 합을 O(1)만에 구하기 위해 사용합니다.
- **정의:** 배열 P의 i번째 요소 P[i]는 원본 배열 A의 0번부터 i번까지의 합입니다
    - $P[i] = A[0] + A[1] + ... + A[i]$
- **특징:** 구간 [s, e]의 합을 구할 때, $P[e] - P[s-1]$만으로 계산이 끝납니다.

```jsx
function prefixSumExample() {
  const A = [10, 20, 30, 40, 50]; // 원본 배열
  const n = A.length;
  const P = new Array(n).fill(0);

  // 1. 누적합 배열 생성: O(N)
  P[0] = A[0];
  for (let i = 1; i < n; i++) {
    P[i] = P[i - 1] + A[i];
  }

  // 2. 구간 합 구하기: O(1)
  // 예: 인덱스 1부터 3까지의 합 (20 + 30 + 40)
  const querySum = (s, e) => {
    if (s === 0) return P[e];
    return P[e] - P[s - 1];
  };

  console.log("누적합 배열:", P); // [10, 30, 60, 100, 150]
  console.log("인덱스 1~3의 합:", querySum(1, 3)); // 90
}

prefixSumExample();
```
## 차분 배열
> 구간 업데이트를 O(1)에 해결하기 위해 사용

원본 배열 `A`에 대해 차분 배열 `D`를 다음과 같이 정의합니다.
- $D[i] = A[i] - A[i-1]$
- 즉, $A[i]$의 값은 $D[0]$부터 $D[i]$까지의 **누적합**과 같습니다.

구간 $[s, e]$에 값 $v$를 더하고 싶다면?
1. `D[s] += v` (시작점부터 끝까지 `v`가 더해지는 효과를 줌)
2. `D[e + 1] -= v` (끝점 이후부터는 다시 `v`를 빼서 원래 상태로 돌림)

```jsx
function differenceArrayExample() {
  const n = 5;
  const A = [0, 0, 0, 0, 0]; // 원본 배열
  const D = new Array(n + 2).fill(0); // 차분 배열 (인덱스 여유분 +2)

  // 업데이트 함수: O(1)
  const update = (s, e, v) => {
    D[s] += v;
    D[e + 1] -= v;
  };

  // 작업 수행
  update(1, 3, 2); // 1~3번에 +2
  update(2, 4, 3); // 2~4번에 +3

  // 최종 결과 복원: O(N)
  let currentSum = 0;
  for (let i = 1; i <= n; i++) {
    currentSum += D[i];
    A[i - 1] = currentSum;
  }

  console.log("차분 배열 결과:", A); // [2, 5, 5, 3, 0]
}

differenceArrayExample();
```

## 구간 합치기
> 겹치는 구간들을 합치는 기법
1. 구간들을 **시작점 기준**으로 정렬합니다.
2. 현재 구간의 시작점이 이전 구간의 끝점보다 작거나 같으면 **합칩니다.**
3. 그렇지 않으면 새로운 독립된 구간으로 둡니다.

```jsx
function mergeIntervalsExample() {
  // 시작점 기준 정렬되지 않은 구간들
  const intervals = [[1, 5], [10, 15], [3, 8]];

  // 1. 시작점 기준 오름차순 정렬: O(M log M)
  intervals.sort((a, b) => a[0] - b[0]);

  if (intervals.length === 0) return [];

  // 2. 순회하며 합치기: O(M)
  const merged = [intervals[0]];

  for (let i = 1; i < intervals.length; i++) {
    const last = merged[merged.length - 1];
    const curr = intervals[i];

    if (curr[0] <= last[1]) {
      // 현재 구간의 시작점이 이전 끝점보다 작거나 같으면 합침
      last[1] = Math.max(last[1], curr[1]);
    } else {
      // 겹치지 않으면 새로운 구간 추가
      merged.push(curr);
    }
  }

  console.log("구간 합치기 결과:", merged); // [[1, 8], [10, 15]]
}

mergeIntervalsExample();
```
