## in JS

자바스크립트의 비트 마스크를 구현할 때 가장 중요한 것은 JS에서 비트 연산은 내부적으로 32 비트 정수로 변환되어 처리됨

따라서 32개 이상의 상태를 관리해야할 때는 `Unit32Array` 를, 32개 미만인 경우에는 일반 변수 하나 사용
### 소규모 비트 마스크

```jsx
// 1. 상태 정의 (2의 거듭제곱으로 정의)
const READ    = 1 << 0; // 1 (0001)
const WRITE   = 1 << 1; // 2 (0010)
const EXECUTE = 1 << 2; // 4 (0100)
const DELETE  = 1 << 3; // 8 (1000)

let myPermissions = 0;

// 2. 상태 추가 (OR 연산)
myPermissions |= READ;
myPermissions |= WRITE; // 현재: 0011 (3)

// 3. 상태 확인 (AND 연산)
const canWrite = (myPermissions & WRITE) !== 0; // true
const canDelete = (myPermissions & DELETE) !== 0; // false

// 4. 상태 제거 (NOT + AND 연산)
myPermissions &= ~WRITE; // WRITE 비트만 0으로 만들고 나머지 유지

// 5. 상태 토글 (XOR 연산 - 있으면 끄고 없으면 켬)
myPermissions ^= EXECUTE;
```

### 대규모 비트마스크

```jsx
class BitMask {
  constructor(size) {
    // 32비트 단위로 공간 확보
    this.buffer = new Uint32Array(Math.ceil(size / 32));
  }

  // 특정 위치의 비트 켜기
  set(index) {
    const block = index >>> 5; // index / 32
    const offset = index & 31; // index % 32
    this.buffer[block] |= (1 << offset);
  }

  // 특정 위치의 비트 끄기
  clear(index) {
    const block = index >>> 5;
    const offset = index & 31;
    this.buffer[block] &= ~(1 << offset);
  }

  // 특정 위치의 비트 확인
  get(index) {
    const block = index >>> 5;
    const offset = index & 31;
    return (this.buffer[block] & (1 << offset)) !== 0;
  }

  // 특정 위치의 비트 반전
  toggle(index) {
    const block = index >>> 5;
    const offset = index & 31;
    this.buffer[block] ^= (1 << offset);
  }
}

// 예시: 1,000개의 체크박스 상태 관리
const checklist = new BitMask(1000);
checklist.set(500);
console.log(checklist.get(500)); // true
console.log(checklist.get(499)); // false
```

### 알고리즘 실전

**전체 완료 확인**

```jsx
const N = 5; 
const FULL_MASK = (1 << N) - 1; // 11111 (2진수) = 31 (10진수)

let currentStatus = 0;

// 비트를 하나씩 채움 (예: 0, 1, 2, 3, 4번 항목 완료)
currentStatus |= (1 << 0);
currentStatus |= (1 << 1);
// ... 과정 반복

// 전부 다 찼는지 확인
if (currentStatus === FULL_MASK) {
    console.log("모든 항목 수집 완료!");
}
```

**포함 관계 확인**

```jsx
const target = (1 << 0) | (1 << 2); // 0번과 2번이 반드시 필요함 (101)
let current = (1 << 0) | (1 << 1) | (1 << 2); // 0, 1, 2번을 가짐 (111)

// (A & B) === B 공식: B의 모든 비트가 A에 들어있는가?
if ((current & target) === target) {
    console.log("필요한 조건을 모두 만족함");
}
```

**켜져 있는 비트 개수 세기**

```jsx
// 가장 대중적인 루프 방식
function countSetBits(n) {
    let count = 0;
    while (n > 0) {
        n &= (n - 1); // 가장 오른쪽에 있는 1을 제거하는 마법의 연산
        count++;
    }
    return count;
}

console.log(countSetBits(currentStatus)); // 현재 켜진 비트 개수 출력
```
