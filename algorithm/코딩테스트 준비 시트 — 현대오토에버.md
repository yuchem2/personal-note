## 1. BFS / DFS

### 격자 BFS (최단거리)

```python
def bfs(grid, sr, sc):
    N, M = len(grid), len(grid[0])
    dist = [[-1]*M for _ in range(N)]      # 방문 + 거리 동시 관리
    dist[sr][sc] = 0
    q = deque([(sr, sc)])
    while q:
        r, c = q.popleft()
        for dr, dc in ((-1,0),(1,0),(0,-1),(0,1)):
            nr, nc = r+dr, c+dc
            if 0 <= nr < N and 0 <= nc < M and dist[nr][nc] == -1 and grid[nr][nc] == 0:
                dist[nr][nc] = dist[r][c] + 1
                q.append((nr, nc))          # ★ 넣을 때 방문 표시
    return dist
```

**필수 규칙**

- `list.pop(0)` 금지 → `deque.popleft()` (pop(0)은 O(N))
- 방문 표시는 **큐에 넣을 때**. 꺼낼 때 하면 중복 삽입 폭발
- `[[0]*M for _ in range(N)]` — `[[0]*M]*N` 은 참조 공유 버그

### 상태 확장 BFS
벽 부수기 / 열쇠 보유 / 시간대별 이동 → `visited[r][c][state]` 차원 추가
### 0-1 BFS (가중치가 0/1뿐)

```python
dq = deque([start])
while dq:
```

## 2. 다익스트라

```python
def dijkstra(adj, start, n):
    INF = float('inf')
    dist = [INF] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:          # ★ 이 줄 없으면 시간초과
            continue
        for v, w in adj[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```

- O(E log V) · **음수 간선이면 사용 불가** (→ 벨만-포드)
- `heapq`는 최소힙. 최대힙은 `-값`
- 튜플은 첫 원소부터 비교 → `(거리, 노드)` 순서 유지
- **한 힙에 int와 tuple을 섞으면 TypeError** — 타입 통일할 것
### 모델링이 핵심 (기출 2번)

정점이 격자가 아니라 **선분·구간·좌표**로 주어지면:

1. 무엇이 정점인가? (교점? 구간 끝? 상태?)
2. 언제 간선이 생기는가?
3. 가중치는 무엇인가?

> 선분 교점: `(x1-x2)(y3-y4) - (y1-y2)(x3-x4) == 0` 이면 평행/동일 축평행 선분끼리면 케이스 분류(수직×수평)가 더 빠름

## 7. 차분 배열 (구간 업데이트 O(1))

> "구간 [s,e]에 v를 더하라"가 **여러 번** 반복될 때. 매번 더하면 O(N·Q), 차분이면 O(N+Q)

```python
D = [0] * (N + 2)              # 여유분 +2

def update(s, e, v):           # A[s..e] 에 v 더하기 — O(1)
    D[s] += v
    D[e+1] -= v

# 마지막에 한 번만 복원 — O(N)
res, cur = [], 0
for i in range(N):
    cur += D[i]
    res.append(cur)
```

**원리**: `A[i] = D[0] + D[1] + ... + D[i]` (차분의 누적합이 원본)

## 9. 구간 처리

### 구간 합치기

```python
def merge(iv):
    iv = sorted(iv, key=lambda x: x[0])     # 시작점 정렬
    out = [iv[0][:]]                        # ★ 복사 (원본 보호)
    for s, e in iv[1:]:
        if s <= out[-1][1]:                 # 겹침

            out.append([s, e])
    return out
```

## 10. 유니온파인드 · MST

```python
class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]      # 경로 압축 (반복문)
            x = self.p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False              # 이미 같은 집합 = 사이클
        if self.r[ra] < self.r[rb]: ra, rb = rb, ra
        self.p[rb] = ra
        if self.r[ra] == self.r[rb]: self.r[ra] += 1
        return True
```

용도: 연결성 판단, 사이클 검출, 크루스칼

### 크루스칼 MST

```python
def kruskal(n, edges):          # edges = [(w, u, v), ...]
    dsu = DSU(n)
    total = 0
    for w, u, v in sorted(edges):
        if dsu.union(u, v):
            total += w
    return total
```

## 11. 위상정렬 (순서 / 선후관계)

```python
def topo(n, edges):
    adj = defaultdict(list)
    indeg = [0] * n
    for u, v in edges:
        adj[u].append(v)
        indeg[v] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    out = []
    while q:
        u = q.popleft()
        out.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return out if len(out) == n else []      # [] 면 사이클 존재
```

> "A는 B보다 먼저" 같은 조건이 나오면 이것. 사전순 필요하면 `deque` 대신 `heapq`

## 12. 플로이드-워셜 (모든 쌍 최단, N ≤ 400)

```python
for k in range(n):
    for i in range(n):
        if d[i][k] == INF: continue          # 가지치기
        dik = d[i][k]
        for j in range(n):
            if dik + d[k][j] < d[i][j]:
                d[i][j] = dik + d[k][j]
```

> **k가 가장 바깥** 루프. 순서 바꾸면 틀림

|하지 말 것|대신|
|---|---|
|`list.pop(0)` — O(N)|`deque.popleft()`|

|반복문으로 단순 집계|`sum` / `max` / `map` / 컴프리헨션|
|반복 `print`|리스트에 모아 `'\n'.join()`|

**핵심 원리**: Python은 **인터프리터 루프를 도는 게 비싸다.** 루프를 C로 넘기면(`sum`, `map`, `sorted`) 10배 이상 빨라진다. _(반대로 JS는 for문이 가장 빠름 — JIT. 언어별로 정반대이니 주의)_

**미세 최적화는 값이 없다**: `row = arr[i]` 캐싱은 실측 1.12배뿐. 시간초과는 **자료구조 선택**과 **복잡도**에서 갈린다.
