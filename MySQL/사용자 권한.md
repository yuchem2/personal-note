## 권한 부여
[사용자 계정](사용자%20계정%20관리.md)에 권한을 부여할 때는 `GRANT` 명령을 사용한다. 
```sql
# GRANT 권한 ON 적용벙뮈 TO 사용자 계정
GRANT privileg_list ON db.table TO 'user'@'host';

# 글로벌 권한
# 적용범위를 지정할 수 없음으로 *.*를 이용한다. *.*은 모든 DB의 오브젝트를 포함한 MySQL 서버 전체를 의미한다.
GRANT SUPER ON *.* TO 'user'@'localhost';

# DB 권한
# DB 권한은 db.table로 오브젝트(테이블)까지 명시할 수 없다.
GRANT EVENT ON *.* TO 'user'@'localhost';
GRANT EVENT ON employees.* TO 'user'@'localhost';

# 테이블 권한
GRANT SELECT,INSERT,UPDATE,DELETE ON *.* TO 'user'@'localhost';
GRANT SELECT,INSERT,UPDATE,DELETE ON employees.* TO 'user'@'localhost';
GRANT SELECT,INSERT,UPDATE,DELETE ON employees.department TO 'user'@'localhost';

# 테이블의 특정 칼럼 권한
# 아래 명령어는 SELETE, INSERT는 department의 모든 칼럼에 적용할 수 있지만, UPDATE는 dept_name 칼럼에만 수행할 수 있다.
GRANT SELECT,INSERT,UPDATE(dept_name) ON employees.department ON 'user'@'localhost';
```
MySQL 8.0부터는 존재하지 않는 사용자에 대해 `GRANT` 명령이 실행되면 에러가 발생된다. `GRANT OPTION` 권한은 다른 권한가 달리 `GRANT` 명령의 마짐지막에 `WITH GRANT OPTION`을 명시해서 부여한다. 

**칼럼 단위의 권한이 하나라도 설정되면 나머지 모든 테이블의 모든 칼럼에 대해서도 권한 체크를 하기 때문에 전체적인 성능에 영향을 미칠 수 있다.** 그러므로, 칼럼단위의 접근이 꼭 필요하면 하나의 칼럼만으로 별도의 뷰를 만들어 사용할 수 있다.

각 계정이나 권한에 부여된 권한이나 역할을 확인하기 위해서는 `SHOW GRANTS`나 mysql DB의 권한 관련 테이블을 참조하면 된다.
- 정적 권한
    - `mysql.user`: 계정 정보 & 계정이나 역할에 부여된 글로벌 권한
    - `mysql.db`: 계정이나 역할에 DB 단위로 부여된 권한
    - `mysql.tables_priv` 계정이나 역할에 테이블 단위로 부여된 권한
    - `mysql.colums_priv`: 계정이나 역할에 칼럼 단위로 부여된 권한
    - `mysql.procs_priv`: 계정이나 역할에 스토어드 프로그램 단위로 부여된 권한
    - `mysql.global_grants`: 계정이나 역할에 부여되는 동적 글로벌 권한
- 동적 권한
    - `mysql.global_grants`: 계정이나 역할에 부여되는 동적 글로벌 권한
## 정적 권한
> MySQL 5.7 버전까지 권한은 글로벌 권한과 객체 권한으로 구분됬다. 8.0에 동적 권한이 추가되면서 기존 권한은 정적 권한으로 명명되었다. (소스 코드 고정적으로 명시되어 있는 권한)

정적 권한은 글로벌 권한과 객체 권한으로 구분한다.
- 글로벌 권한: 데이터베이스나 테이블 이외의 객체에 적용되는 권한
- 객체 권한: 데이터베이스나 테이블을 제어하는 데 필요한 권한

객체 권한은 `GRANT` 명령어로 권한을 부여할 때 반드시 특정 객체를 명시해야 하며, 반대로 글로벌 권한은 `GRANT` 명령에서 특정 객체를 명시해야 하지 말아야 한다. **예외적으로 `ALL`(또는 `ALL PRIVILEGES`)은 글로벌과 객체 권한 두 가지 용도로 사용될 수 있다.** 특정 객체에 `ALL` 권한이 부여되면 해당 객체에 적용될 수 있는 모든 객체 권한을 부여하며, 글로벌로 `ALL`이 사용되면 글로벌 수준에서 가능한 모든 권한을 부여한다.

## 동적 권한
MySQL 8.0버전부터 추가된 권한으로, MySQL 서버가 시작되면서 동적으로 생성하는 권한을 의미한다. (일부는 서버에 명시돼 있기도 하다). 예를 들면 컴포넌트나 플러그인이 설치되면 등록되는 권한을 동적 권한이라고 한다.

MySQL 5.7 버전까지는 `SUPER` 권한이 데이터베이스 관리를 위해 필요한 권한이었지만, MySQL 8.0 버전부터 `SUPER` 권한은 잘게 쪼개져 아래 표의 동적 권한으로 분산됐다. *이로써 개별로 꼭 필요한 권한만 부여할 수 있게 됐다.*
