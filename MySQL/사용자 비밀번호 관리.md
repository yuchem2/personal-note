## 고수준 비밀번호

MySQL 8.0 버전부터 서버에서 비밀번호 유효성 체크 규칙을 추가하려면 `validate_password` 컴포넌트를 설치해야 한다. 서버 프로그램에 내장되어 있기 때문에 별도의 파일 경로 없이 설치할 수 있다.

> MySQL 5.7 버전까지는 `validate_password`가 별도의 플러그인 형태로 제공되었지만 컴포넌트로 제공된다. 사용자 측면에서는 거의 동일한 기능을 제공하며, 시스템 변수 이름에만 차이가 있다.

```mysql
INSTALL COMPONENT 'file://component_validate_password';

# 설치된 컴포넌트 확인
SELECT * FROM mysql.component;
# 제공하는 시스템 변수 확인
SHOW GLOBAL VARIABLES LIKE 'validate_password%';
```

해당 컴포넌트를 설치하면 제공되는 시스템 변수는 다음과 같다.
- `validate_password.check_user_name`: 비밀번호에 사용자 이름이 포함 통과 여부
- `validate_password.dictionary_file`: 금칙어 설정. 한 줄에 하나씩 기록해서 파일로 저장해 그 파일 이름을 지정하면 된다.
- `validate_password.length`: 비밀번호 길이 제한
- `validate_password.mixed_case_count`: 사용된 대소문자 제한
- `validate_password.number_count`: 숫자 제한
- `validate_password.policy`: 비밀번호 정책
    - `LOW`: 비밀번호의 길이만 검증
    - `MEDIUM`: 길이 검증 및 숫자와 대소문자, 그리고 특수문자 배합의 수 검증
    - `STRONG`: `MEDIUM` 레벨의 검증을 모두 수행하며 금칙어 포함 여부 검증
- `validate_password.special_char_count`: 특수문자 제한
## 이중 비밀번호 (Daul Password)
MySQL 8.0부터 지원된 기능으로, 계정의 비밀번호로 2개의 값을 동시에 사용할 수 있는 기능. 데이터베이스 비밀번호는 보안을 위해 주기적으로 변경해야 하지만, 서비스를 멈추지 않고서는 바꾸기가 어렵기 때문에 이 기능이 도입되었다.

2개의 비밀번호는 Primary와 Secondary로 구분된다. 최근에 설정된 비밀번호가 Primary, 이전 비밀번호가 Secondary가 된다. 해당 기능을 사용하려면 비밀번호 변경 구문에 `RETAIN CURRENT PASSWORD` 옵션을 추가해야 한다.

```mysql
# old_password 가 secondary, new_password가 primary 비밀번호
ALTER USER 'root'@'localhost' IDENTIFIED BY 'old_password';
ALTER USER 'root'@'localhost' IDENTIFIED BY 'new_password' RETAIN CURRENT PASSWORD;
# 모든 이관이 끝나면, 보안을 위해 secondary 비밀번호는 삭제하는 것이 좋다.
ALTER USER 'root'@'localhost' DISCARD OLD PASSWORD;
```
