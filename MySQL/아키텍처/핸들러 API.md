[MySQL 엔진](MySQL%20엔진.md)의 쿼리 실행기에서 데이터를 쓰거나 읽어야 할 때는 각 [스토리지 엔진](스토리지%20엔진.md)에 쓰기 또는 읽기를 요청한다. 이를 핸들러 요청이라고 하고, 여기에 사용되는 API를 핸들러 API라고 한다. 핸들러 API를 통해 [MySQL 엔진](MySQL%20엔진.md)과 [스토리지 엔진](스토리지%20엔진.md)이 데이터를 주고 받는다. 

`SHOW GLOBAL STATUS LIKE 'Handler%'` 명령으로 핸들러 API가 수행한 데이터(레코드) 작업 양을 확인할 수 있다.

[MySQL 엔진](MySQL%20엔진.md)이 각 [스토리지 엔진](스토리지%20엔진.md)에게 데이터를 읽어오거나 저장하도록 하려면 반드시 핸들러를 통해야만 한다. 핸들러는 결국 [스토리지 엔진](스토리지%20엔진.md)이라 할 수 있다.
