[MySQL 엔진](MySQL%20엔진.md)은 다음과 같은 과정으로 쿼리 문장을 실행한다.
1. 사용자의 SQL 요청
2. **쿼리 파서**가 사용자의 쿼리 문장을 토큰으로 분리해 트리 형태의 구조로 만듦(기본 문법 오류 식별)
3. 파서 트리를 기반으로 **전처리기**가 구조적인 문제점을 확인. 객체의 존재 여부와 객체의 접근 권한 등을 확인함
4. **옵티마이저**가 쿼리 문장을 저렴한 비용으로 가장 빠르게 처리할 수 있는 방법을 결정
5. **실행 엔진(쿼리 실행기)** 이 옵티마이저의 계획대로 핸들러에게 요청하고, 그 결과를 다른 핸들러에게 전달하는 등의 행위를 통해 실행 결과를 생성
6. 쿼리 실행 결과가 사용자에게 노출
