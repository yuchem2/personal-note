MySQL 메모리 영역은 크게 글로벌 영역과 로컬 영역으로 구분할 수 있다. 
## 글로벌 영역
모든 메모리 공간은 MySQL 서버가 시작되면서 운영체제로부터 할당된다. 일반적으로 [클라이언트 스레드](MySQL%20스레딩%20구조.md#포그라운드%20스레드)의 수와 무관하게 하나의 메모리 공간만 할당된다. 필요에 따라 2개 이상을 할당받을 수 있지만, 이는 [클라이언트 스레드](MySQL%20스레딩%20구조.md#포그라운드%20스레드)와 무관하다. 생성된 영역이 N개라 하여도 모든 스레드에 의해 공유된다. 대표적인 영역은 다음과 같다.
- 테이블 캐시
- 바이너리 로그 버퍼
- MyISAM 키 캐시
- InnoDB 버퍼 풀
- InnoDB 어댑티브 해시 인덱스
- InnoDB 리두 로그 버퍼
## 로컬 영역
세션 메모리 영역이라고도 하며, MySQL 서버상의 존재하는 [클라이언트 스레드](MySQL%20스레딩%20구조.md#포그라운드%20스레드)가 쿼리를 처리하는 데 사용하는 메모리 영역. 

각 [클라이언트 스레드](MySQL%20스레딩%20구조.md#포그라운드%20스레드)별로 독립적으로 할당되며 절대 공유되어 사용되지 않는다. 로컬 메모리는 각 쿼리의 용도별로 필요할 때만 공간이 할당되고, 필요하지 않는 경우는 공간할당도 하지 않는 경우가 있다. 커넥션과 생명 주기를 같이 하는 공간(커넥션 버퍼나 결과 버퍼)도 있고, 그렇지 않고 쿼리를 실행하는 순간에만 할당하는 공간(소트 버퍼나 조인 버퍼)도 있다.

대표적인 영역은 다음과 같다.
- 정렬 버퍼
- 조인 버퍼
- 바이너리 로그 캐시
- 네트워크 버퍼
- 리드 버퍼
