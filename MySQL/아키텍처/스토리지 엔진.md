실제 데이터를 디스크 스토리지에 저장하거나 디스크 스토리지로부터 데이터를 읽어오는 부분을 담당한다. 동시에 여러 스토리지 엔진을 사용할 수 있으며 아래와 같은 명령어로 테이블이 사용할 스토리지 엔진을 지정할 수도 있다.

```sql
CREATE TABLE test_table (fd1, INT, fd2 INT) ENGINE=INNODB;
```

각 스토리지 엔진은 성능 향상을 위해 키 캐시([MyISAM 스토리지 엔진](MyISAM%20스토리지%20엔진.md))나 InnoDB 버퍼 풀([InnoDB 스토리지 엔진](InnoDB%20스토리지%20엔진.md))과 같은 기능을 내장하고 있다.
## 지원되는 스토리지 엔진
MySQL은 기본적으로 플러그인을 통해 다양한 스토리지 엔진을 지원한다. 또한, 직접 스토리지 엔진을 개발할 수도 있다. `SHOW ENGINES`를 통해 mysqld에서 지원하는 스토리지 엔진을 확인할 수 있다.

- ARCHIVE
- BLACKHOLE
- MRG_MYISAM
- FEDERATED
- [MYISAM](MyISAM%20스토리지%20엔진.md)
- PERFORMANCE_SCHEMA
- [InnoDB](InnoDB%20스토리지%20엔진.md)
- MEMORY
- CSV

> 각 엔진은 플러그인 형태로 제공되는데, `SHOW PLUGINS` 명령을 통해도 확인할 수 있다. 이때 인증 및 검색용 파서와 같은 플러그인(설치되어 있다면)도 확인할 수 있다.
