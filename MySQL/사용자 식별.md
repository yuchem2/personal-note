```mysql
'svc_id'@'127.0.0.1'
'svc_id'@'192.168.0.1'
'svc_id'@'%'
```

MySQL의 사용자는 사용자의 계정뿐 아니라 사용자의 접속 지점도 계정의 일부가 된다. `@`를 기준으로 좌항에는 사용자의 계정, 우항에는 사용자의 접속 지점을 넣어 각 사용자를 식별한다. 즉, 위의 3가지 계정은 모두 다른 계정으로 판단된다. 이때 `%`는 모든 IP 또는 모든 호스트명을 의미한다. **권한과 계정 정보에 대해 MySQL은 범위가 작은 것을 항상 먼저 선택한다.** 그러므로, 만약 `192.168.0.1`에서 접속하면 항상 `%` 범위의 계정으로는 로그인할 수 없다.
