MySQL 서버는 기동하면서 설정 파일의 내용을 읽어 메모리나 작동 방식을 초기화하고, 접속된 사용자를 제어하기 위해 이 값들을 별도로 저장한다. 이 저장된 값을 시스템 변수라고 한다.

```mysql
/* 아래 명령어를 통해 시스템 변수를 조회할 수 있다. */
SHOW GLOBAL VARIABLES;
SHOW VARIABLES;
```

시스템 변수에는 글로벌 변수와 세션 변수가 나눠져 있고, 각 시스템 변수는 5가지 속성으로 구분할 수 있다.

- Cmd-Line: MySQL 서버의 명령행 인자로 설정될 수 있는 여부
- Option file: MySQL 서버의 설정 파일인 `my.cnf`로 제정할 수 있는지 여부
- System Var: 시스템 변수인지 여부
- Var Scope: 시스템 변수의 적용 범위를 나타낸다. Global, Session, Both로 구분한다.
- Dynamic: 시스템 변수가 동적인지 여부
