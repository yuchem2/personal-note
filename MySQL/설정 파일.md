데이터베이스의 구동 방식, 성능 옵션, 네트워크 연결 등을 제어하는 핵심 텍스트 파일. MySQL에서는 일반적으로 단 하나의 설정 파일을 사용한다. 리눅스 계열에서는 `my.cnf`, 윈도우 환경에서는 `my.ini`라는 이름을 사용한다. 

```shell
> mysqld --verbose --help
> mysql --help
```

> 실제 MySQL 서버는 단 하나의 설정 파일만을 사용하지만, 설정 파일이 위치한 디렉토리는 여러 곳일 수 있다.

위 명령어를 통해 어느 디렉토리에서 설정 파일을 읽는 지 확인할 수 있다. 위의 명령은 많은 정보가 나오지만, `Default options are read ...`라는 부분을 보면 MySQL 서버나 클라이언트 프로그램이 순서대로 어디에 있는 설정 파일을 참조하는 지 알 수 있다.
## 구성
설정 파일은 하나의 파일에 여러 개의 설정 그룹을 담을 수 있으며, 대체로 실행 프로그램 이름을 그룹명으로 사용한다. 예를 들어 `mysqldump` 프로그램은 `[mysqldump]` 설정 그룹을, `mysqld` 프로그램ㅇ느 설정 그룹의 이름이 `[mysqld]`인 영역을 참조한다.

```text
[mysqld_safe]
malloc-lib = /opt/lib/libtcmalloc_minimal.so

[mysqld]
socket = /usr/local/mysql/tmp/mysql.sock
port = 3306

[mysql]
default-character-set = utf8mb4
socket = /usr/local/mysql/tmp/mysql.sock
port = 3304

[mysqldump]
default-character-set = utf8mb4
socket = /usr/local/mysql/tmp/mysql.sock
```

각 그룹에는 [시스템 변수](시스템%20변수.md) 명을 값과 함께 `=`를 이용해 대입할 수 있고, 이를 통해 MySQL은 메모리나 작동 방식을 초기화하고, 접속된 사용자를 제어한다.
